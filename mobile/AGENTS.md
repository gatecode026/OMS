# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v57.0.0/ before writing any code.

## OMS Mobile Design Rules
1. Follow the Design System tokens defined in `src/shared/theme/tokens.ts` at all times.
2. Ensure components support both Light Theme and Dark Theme without hardcoded colors.
3. Every button press, card press, and modal must use spring animations from Reanimated.
4. Touch targets must be at least 48x48 dp and accessible for screen readers.
5. Reuse Design System UI components instead of writing custom inline UI widgets.
